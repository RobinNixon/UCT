\hypertarget{the-five-bit-threshold-for-universal-computation}{%
\section{The Five-Bit Threshold for Universal
Computation}\label{the-five-bit-threshold-for-universal-computation}}

\textbf{Author:} Robin Nixon, Independent Researcher, Author, Software Developer \& AI Researcher

\textbf{Date:} January 2026

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{abstract}{%
\subsection{Abstract}\label{abstract}}

We prove that under natural encodings, every universal computational
system requires at least 5 bits of descriptive complexity. The proof
proceeds by capability decomposition: we show that universal computation
requires four independent capabilities---Logic ($\geq$2 bits), Memory ($\geq$1
bit), Control ($\geq$1 bit), and State ($\geq$1 bit)---and prove their mutual
independence via explicit construction. The bound is tight: Tag(2,2), SK
calculus, and Rule 110 each achieve exactly 5 bits under specification
complexity.

We conjecture this bound reflects a deeper constraint: that universal
computation inherently requires the descriptive complexity to encode
\textbf{Control}---the capacity for conditional, context-dependent state
transitions. At 4 bits, systems can exhibit self-organization but
collision outcomes remain uniform; the 5th bit enables outcomes to
depend on context, which is the essence of computation.

Through systematic analysis of 6,500+ computational systems across eight
substrates, we verify the theorem with zero violations. We invite proof
or refutation of the Control conjecture in alternative substrates.

\textbf{Keywords:} Universal computation, Turing completeness, cellular
automata, computational complexity, information theory, capability
decomposition

\textbf{Repository:} Complete code, data, and supporting materials available at \url{https://github.com/RobinNixon/UCT}

\hypertarget{introduction}{%
\subsection{1. Introduction}\label{introduction}}

\hypertarget{the-central-question}{%
\subsubsection{1.1 The Central Question}\label{the-central-question}}

What is the simplest possible system capable of universal computation?
This question has fascinated researchers since Turing's foundational
work on computability {[}1{]}. While the Church-Turing thesis
establishes that many computational formalisms are equivalent in power,
it says nothing about the \emph{minimum resources} required to achieve
this power.

Previous work has identified remarkably small universal systems: Rule
110 cellular automata {[}2{]}, small Turing machines {[}3{]}, and tag
systems {[}6{]}. A striking pattern emerges: despite radically different
formalisms, the smallest universal systems cluster around similar
descriptive complexities.

This paper investigates whether this pattern reflects a fundamental
limit.

\hypertarget{main-results}{%
\subsubsection{1.2 Main Results}\label{main-results}}

We prove:

\textbf{Theorem (Five-Bit Threshold).} Under natural encodings
(Definition 2.3), every universal computational system requires at least
5 bits of descriptive complexity.

The proof establishes: 1. \textbf{Capability decomposition:} Universal
computation requires Logic ($\geq$2), Memory ($\geq$1), Control ($\geq$1), State ($\geq$1)
bits 2. \textbf{Independence:} These capabilities are mutually
independent (proven by separation witnesses) 3. \textbf{Additivity:} The
capability bits sum without compression 4. \textbf{Tightness:} Tag(2,2)
achieves exactly 5 bits

\textbf{The Control Conjecture:} We conjecture that the five-bit
threshold reflects a deeper constraint---that universal computation
inherently requires encoding Control, the capacity for conditional,
context-dependent state transitions. Control is context-dependent
divergence in interaction outcome. At 4 bits, systems can possess
Memory, State, and partial Logic, but collision outcomes remain uniform
rather than selective. The 5th bit enables collision outcomes to depend
on context, which is the essence of Control.

\hypertarget{formal-framework}{%
\subsection{2. Formal Framework}\label{formal-framework}}

\hypertarget{computational-systems}{%
\subsubsection{2.1 Computational Systems}\label{computational-systems}}

\textbf{Definition 2.1 (Computational System).} A computational system
is a tuple $C = (Q, \Sigma, \delta, q_0, F)$ where:
\begin{itemize}
\item $Q$ is a finite set of internal states
\item $\Sigma$ is a finite alphabet
\item $\delta: Q \times \Sigma^* \rightarrow Q \times \Sigma^* \times \{L, R, S\}^*$ is the transition function
\item $q_0 \in Q$ is the initial state
\item $F \subseteq Q$ is the set of halting states
\end{itemize}

\textbf{Definition 2.2 (Universality).} A system U is universal
(Turing-complete) if it can simulate any Turing machine.

\hypertarget{natural-encodings}{%
\subsubsection{2.2 Natural Encodings}\label{natural-encodings}}

The following definition is central to our theorem. It captures what we
mean by a ``reasonable'' description of a computational system.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\textbf{Definition 2.3 (Natural Encoding).} A description scheme D is a
\emph{natural encoding} if it satisfies:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Structural correspondence:} Components of the description
  correspond to components of the system (states map to state bits,
  rules map to rule bits, etc.)
\item
  \textbf{Logarithmic costs:} Specifying a choice among n alternatives
  costs $\lceil \log_2 n \rceil$ bits
\item
  \textbf{Compositionality:} The description of a composite system is
  the concatenation of component descriptions plus O(log n) overhead
\item
  \textbf{Extractor-compatible:} The capability extractors E\_L, E\_M,
  E\_K, E\_S are well-defined and non-overlapping
\end{enumerate}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\textbf{Examples of natural encodings:} - Binary encoding of Turing
machine transition tables - Rule number encoding for cellular automata -
Production list encoding for tag systems - Combinator specification for
SK calculus

\textbf{Non-examples (excluded from our claims):} - Encodings where a
single bit encodes multiple independent choices - Encodings using
cryptographic compression - Encodings optimized for a specific system
class at the expense of others

\hypertarget{complexity-measures}{%
\subsubsection{2.3 Complexity Measures}\label{complexity-measures}}

\textbf{Note on Complexity Measures:} For cellular automata, we report
two measures:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Specification complexity K\_spec:} The number of bits set in
  the rule table (popcount). For Rule 110, this is \textbf{5 bits}.
\item
  \textbf{Full descriptive complexity K\_full:} Includes neighborhood
  specification ($\log_2(3) \approx 1.58$ bits for 3-cell neighborhood), totaling
  6.58 bits for Rule 110.
\end{enumerate}

The UCT theorem refers to specification complexity for cross-substrate
comparability. When we say ``Rule 110 achieves 5 bits,'' we mean K\_spec
= 5.

\hypertarget{capability-extractors}{%
\subsubsection{2.4 Capability Extractors}\label{capability-extractors}}

We define four capability extractors---functions identifying the portion
of a description encoding each capability:

\begin{itemize}
\tightlist
\item
  \textbf{E\_L(d):} Extracts bits specifying Boolean operations
\item
  \textbf{E\_M(d):} Extracts bits specifying memory access operations
\item
  \textbf{E\_K(d):} Extracts bits specifying control flow operations
\item
  \textbf{E\_S(d):} Extracts bits specifying state encoding
\end{itemize}

Under natural encodings, these extractors produce non-overlapping bit
regions.

\hypertarget{logic-minimum-2-bits}{%
\subsubsection{3.1 Logic Minimum (2 bits)}\label{logic-minimum-2-bits}}

\textbf{Theorem 3.1.} Any universal system requires $\geq$2 bits for Logic.

\emph{Proof.} 1. Universal computation requires Boolean completeness
{[}11{]} 2. The minimal complete basis is a single 2-input gate (NAND or
NOR) 3. NAND/NOR are the only complete 2-input Boolean functions
(exhaustive verification) 4. Specifying NAND among 16 two-input
functions: identify which of 4 inputs yields 0 5. $\log_2(4) = 2$ bits

\emph{Tightness:} NAND specification achieves exactly 2 bits. $\square$

\hypertarget{memory-minimum-1-bit}{%
\subsubsection{3.2 Memory Minimum (1 bit)}\label{memory-minimum-1-bit}}

\textbf{Theorem 3.2.} Any universal system requires $\geq$1 bit for Memory.

\emph{Proof.} 1. Universal computation requires unbounded storage
{[}1{]} 2. Must distinguish at least READ vs WRITE (or LEFT vs RIGHT for
tape heads) 3. $\log_2(2) = 1$ bit

\emph{Tightness:} Single read/write bit achieves 1 bit. $\square$

\hypertarget{control-minimum-1-bit}{%
\subsubsection{3.3 Control Minimum (1
bit)}\label{control-minimum-1-bit}}

\textbf{Theorem 3.3.} Any universal system requires $\geq$1 bit for Control.

\emph{Proof.} 1. Universal computation requires conditional execution
{[}14{]} 2. Must distinguish CONTINUE vs BRANCH 3. Without branching,
execution is straight-line, recognizing only regular languages 4.
$\log_2(2) = 1$ bit

\emph{Tightness:} Single branch/continue bit achieves 1 bit. $\square$

\hypertarget{state-minimum-1-bit}{%
\subsubsection{3.4 State Minimum (1 bit)}\label{state-minimum-1-bit}}

\textbf{Theorem 3.4.} Any universal system requires $\geq$1 bit for State.

\emph{Proof.} 1. Universal computation must halt (by definition) 2. Must
distinguish COMPUTING vs HALTED states 3. Minsky {[}5{]} proved: All
1-state Turing machines are trivial (purely periodic) 4. $\log_2(2) = 1$ bit

\emph{Tightness:} Single halt bit achieves 1 bit. $\square$

\hypertarget{capability-independence}{%
\subsection{4. Capability Independence}\label{capability-independence}}

\hypertarget{independence-theorem}{%
\subsubsection{4.1 Independence Theorem}\label{independence-theorem}}

Complete separation witnesses and independence proofs are detailed in
\texttt{supplementary/proofs.md}.

\textbf{Theorem 4.1.} Under natural encodings, the four capabilities L,
M, K, S are mutually independent.

\emph{Proof.} We exhibit separation witnesses for each pair:

\begin{longtable}[]{@{}lll@{}}
\toprule\noalign{}
Pair & Has X, lacks Y & Has Y, lacks X \\
\midrule\noalign{}
\endhead
\bottomrule\noalign{}
\endlastfoot
(L,M) & Combinational circuit & Shift register \\
(L,K) & Feedforward circuit & Branch-only FSM \\
(L,S) & Single-state calculator & 2-state trivial machine \\
(M,K) & Linear tape writer & Finite automaton \\
(M,S) & Non-halting memory & Halting FA \\
(K,S) & Infinite brancher & Straight-line halter \\
\end{longtable}

Each separation demonstrates that X-bits and Y-bits encode different
information. $\square$

\hypertarget{additivity-corollary}{%
\subsubsection{4.2 Additivity Corollary}\label{additivity-corollary}}

\textbf{Corollary 4.2.} Under natural encodings:
\[|D(C)| \geq |E_L(d)| + |E_M(d)| + |E_K(d)| + |E_S(d)|\]

\emph{Proof.} By non-overlapping extraction, the substrings are
positionally disjoint. $\square$

\hypertarget{the-feedback-objection}{%
\subsubsection{4.3 The Feedback
Objection}\label{the-feedback-objection}}

\textbf{Potential objection:} ``Logic gates with feedback implement
memory (flip-flops). Don't Logic bits substitute for Memory bits?''

\textbf{Resolution:} A NAND gate requires 2 bits (specifying the gate
type). A NAND-based flip-flop requires those same 2 bits for gate type
PLUS $\geq$2 bits for connection topology (which outputs connect to which
inputs). The topology bits are properly accounted as Memory, not Logic.

Concretely: - Bare NAND gate: 2 bits (Logic only) - NAND-based SR latch:
2 bits (gates) + $\geq$2 bits (topology) = $\geq$4 bits

The feedback topology specification is additional information beyond the
logic operation itself. Under our accounting conventions, these topology
bits are extracted by E\_M, maintaining independence.

\hypertarget{the-five-bit-threshold}{%
\subsection{5. The Five-Bit Threshold}\label{the-five-bit-threshold}}

The formal capability calculus underlying this proof is developed in
\texttt{theory/CAPABILITY\_CALCULUS.md}.

\hypertarget{main-theorem}{%
\subsubsection{5.1 Main Theorem}\label{main-theorem}}

\textbf{Theorem 5.1 (Five-Bit Threshold).} For any universal
computational system C and any natural encoding D (as defined in
Definition 2.3): \[|D(C)| \geq 5 \text{ bits}\]

Moreover, this bound is tight.

\emph{Proof.}

\textbf{Lower Bound:} By Theorems 3.1--3.4: - \textbar E\_L(d)\textbar{}
$\geq$ 2 - \textbar E\_M(d)\textbar{} $\geq$ 1 - \textbar E\_K(d)\textbar{} $\geq$ 1 -
\textbar E\_S(d)\textbar{} $\geq$ 1

By Corollary 4.2: \[|D(C)| \geq 2 + 1 + 1 + 1 = 5\]

\textbf{Tightness:} - Tag(2,2): 5.0 bits {[}6{]} - SK calculus: 5.0 bits
{[}22{]} - Rule 110: 5 bits set in rule table (specification complexity)
{[}2{]}

\begin{figure}[htbp]
\centering
\includegraphics[width=0.85\textwidth]{rule110_dynamics.png}
\caption{Rule 110 spacetime dynamics showing complex, non-periodic behavior---the hallmark of a system at the edge of universality.}
\label{fig:fig2}
\end{figure}

Multiple systems from different substrates achieve exactly 5 bits. $\square$

\hypertarget{four-bit-impossibility}{%
\subsubsection{5.2 Four-Bit
Impossibility}\label{four-bit-impossibility}}

\textbf{Corollary 5.2.} No system with \textbar D(C)\textbar{} $\leq$ 4 is
universal under natural encodings.

\emph{Proof.} If \textbar D(C)\textbar{} = 4, then by additivity some
capability has \textbar E\_X(d)\textbar{} below its minimum. Therefore C
lacks a required capability. $\square$

\hypertarget{scope-conjecture}{%
\subsubsection{5.3 Scope Conjecture}\label{scope-conjecture}}

\textbf{Conjecture 5.3.} The class of natural encodings captures all
structurally reasonable descriptions. We conjecture no encoding admits a
universal system below 5 bits.

This conjecture asserts that our theorem is not merely a statement about
a restricted class of encodings, but reflects a fundamental limit on
universal computation.

\item

\item

\item

\textbf{Non-universality determination:} Systems were classified as
non-universal by: - Proven bounded behavior (all configurations
eventually periodic) - Reduction to known non-universal classes (e.g.,
semilinear sets for 1-counter) - Failure to support required structures
(no gliders, no collision diversity)

\textbf{System counting:} Each distinct rule/transition table counts as
one system. Symmetric variants (reflections, conjugates) are counted
separately as they may have different structural properties.

\hypertarget{necessary-but-not-sufficient}{%
\subsubsection{7.1 Necessary but Not
Sufficient}\label{necessary-but-not-sufficient}}

\textbf{The five-bit threshold is necessary but not sufficient for
universality.} A system must meet the complexity floor ($\geq$5 bits) AND
satisfy structural conditions (asymmetry, collision diversity, directed
information flow). Rule 122 demonstrates this: at 6.58 bits it exceeds
the threshold but fails due to symmetry.

\hypertarget{symmetry-obstruction}{%
\subsubsection{7.2 Symmetry Obstruction}\label{symmetry-obstruction}}

\textbf{Theorem 7.1.} Symmetric 1D cellular automata cannot be
universal.

\emph{Proof.} If rule f commutes with spatial reflection R, then mean
information velocity $\bar{v}$ = 0 for all configurations (symmetric
cancellation). Universal computation requires directional information
transport. $\square$

does not guarantee universality}---structural conditions are essential.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\hypertarget{the-control-conjecture}{%
\subsection{8. The Control Conjecture}\label{the-control-conjecture}}

\hypertarget{statement}{%
\subsubsection{8.1 Statement}\label{statement}}

\textbf{Conjecture (Control as the Critical Capability).} The five-bit
threshold reflects a deeper constraint: universal computation inherently
requires encoding Control---the capacity for conditional,
context-dependent state transitions.

At 4 bits, systems can possess: - Memory (1 bit): Store and retrieve
values - State (1 bit): Track computation progress - Partial Logic (2
bits): Some Boolean operations

But they \emph{cannot} possess Control: the ability for outcomes to
depend on context.

\hypertarget{formal-definition-of-control}{%
\subsubsection{8.2 Formal Definition of
Control}\label{formal-definition-of-control}}

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

\textbf{Definition 8.1 (Control Capability).} A rule R has Control if
collision outcomes depend on context. Formally, R satisfies Control if:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\item
  \textbf{Context dependency:} $\geq$2 distinct collision outcomes for the
  same signal pair under different neighborhood contexts
\item
  \textbf{Non-commuting:} Interaction order affects final state (A then
  B $\neq$ B then A for some signals A, B)
\item
  \textbf{Selectivity:} Multiple distinct outcome types (not just
  pass-through or annihilation)
\end{enumerate}

The \textbf{Control score} C(R) quantifies this as the normalized ratio
of context-dependent collision types to maximum possible collision
outcomes.

\begin{center}\rule{0.5\linewidth}{0.5pt}\end{center}

In essence: \textbf{Control is context-dependent divergence in
interaction outcome.}

\hypertarget{the-mechanistic-explanation}{%
\subsubsection{8.4 The Mechanistic
Explanation}\label{the-mechanistic-explanation}}

\textbf{What 4-bit rules can do:} - Local persistence (memory) -
Phase/register context (state) - Simple interference (partial logic)

\textbf{What 4-bit rules cannot do:} When signals collide, outcomes are
\emph{uniform}: - Pass-through (linear) - Always-kill or always-explode
- Periodic interference

\textbf{What the 5th bit enables:} - A \textbf{collision algebra} with
context-dependent outcomes - Transition roles tunable independently
(birth, death, survival, transformation) - Collisions implement
\textbf{branching and gating}

The 5th bit is not ``more activity''---it is the minimum needed to make
collision outcomes \emph{conditional rather than uniform}.

\hypertarget{optimality-why-more-bits-dont-help}{%
\subsection{9. Optimality: Why More Bits Don't

\hypertarget{the-inverted-u-curve}{%
\subsubsection{9.1 The Inverted-U Curve}\label{the-inverted-u-curve}}

A remarkable finding: \textbf{5 bits is not just the minimum for
universality---it is the optimum.}

Analysis of rules from 5 to 7 bits reveals diminishing returns:

\begin{longtable}[]{@{}llll@{}}
\toprule\noalign{}
Transition & Glider Types & Oscillators & Collision Diversity \\
\midrule\noalign{}
\endhead
\bottomrule\noalign{}
\endlastfoot
5 $\rightarrow$ 6 bits & -9.7\% & -25.7\% & -42.2\% \\
6 $\rightarrow$ 7 bits & -21.6\% & -40.5\% & -59.7\% \\
\end{longtable}

As more bits are set in the rule table, dynamics become increasingly
trivial. The computational richness peaks at 5 bits and declines
thereafter.

\hypertarget{why-this-happens}{%
\subsubsection{9.2 Why This Happens}\label{why-this-happens}}

At low bit counts (0-4), rules lack the complexity for computation. At 5
bits, rules have exactly enough structure for conditional dynamics. At
high bit counts (6+), rules approach the ``all-1s'' trivial rule, losing
structure.

The 5-bit point sits at the peak of the inverted-U: enough complexity
for Control, but not so much that dynamics become uniform.

\hypertarget{universality-is-binary}{%
\subsubsection{9.3 Universality is
Binary}\label{universality-is-binary}}

Above the threshold, additional bits provide convenience but not
capability: - More glider types (initially) - Faster signal propagation
- Richer collision vocabulary

But universality itself is binary---a system either can simulate all TMs
or cannot. The 5-bit threshold marks where this capability first becomes
possible.

\hypertarget{the-self-organization-threshold}{%
\subsubsection{10.1 The Self-Organization
Threshold}\label{the-self-organization-threshold}}

We observe a distinct lower threshold: the \textbf{Self-Organization
Threshold (SOT)} at approximately 3 bits.

\begin{longtable}[]{@{}lll@{}}
\toprule\noalign{}
Threshold & Value & Capability \\
\midrule\noalign{}
\endhead
\bottomrule\noalign{}
\endlastfoot
SOT & \textasciitilde3 bits & Pattern formation, memory,
self-organization \\
UCT & 5 bits & Universal computation \\
Gap & \textasciitilde2 bits & Transition from structure to control \\
\end{longtable}

\textbf{Evidence for SOT:} - Conway's Life (B3/S23) at \textasciitilde3
bits shows rich self-organization but is below UCT - The two-peaks
analysis shows activity emerging at 4 bits, computation at 5 bits -
Intermediate rules (4 bits) show maximum activity but minimum
computational structure---a ``chaos valley''

\textbf{SOT Capability Decomposition:} - Memory (1 bit): Store patterns
- State (1 bit): Track configurations - Partial Logic (\textasciitilde1
bit): Some Boolean operations

SOT lacks Control---systems can organize but cannot compute. The 2-bit
gap between SOT and UCT represents the acquisition of Control.

\hypertarget{implications-for-origin-of-life}{%
\subsubsection{10.2 Implications for Origin of
Life}\label{implications-for-origin-of-life}}

If the five-bit threshold is fundamental, any physical or chemical
system achieving universality must encode $\geq$5 bits of ``programmatic''
structure. This suggests:

\begin{itemize}
\tightlist
\item
  \textbf{Abiogenesis stages:} Chemistry (2-4 bits) $\rightarrow$ Proto-life (5-7
  bits) $\rightarrow$ True life (10+ bits)
\item
  The \textasciitilde5-bit threshold may mark the chemistry $\rightarrow$ biology
  transition
\item
  Minimum complexity for hereditary computation $\approx$ UCT
\end{itemize}

\hypertarget{physical-realizability}{%
\subsubsection{10.3 Physical
Realizability}\label{physical-realizability}}

Energy conservation adds zero overhead to the threshold. The Margolus
BBM achieves universality at 5.64 bits with full conservation and
reversibility. Physical constraints do not increase UCT.

\hypertarget{binary-optimality}{%
\subsubsection{10.4 Binary Optimality}\label{binary-optimality}}

Binary (2-state) systems achieve the minimum threshold. Ternary systems
have threshold \textasciitilde7.5 bits due to exponentially larger rule
tables. More states provide no savings---binary is optimal.

\hypertarget{conclusion}{%
\subsection{11. Conclusion}\label{conclusion}}

We have proven the five-bit threshold for universal computation under
natural encodings, via capability decomposition connecting to classical
results {[}5, 11, 14, 1{]}.

The threshold is: - \textbf{Proven:} 2 + 1 + 1 + 1 = 5 bits minimum -
\textbf{Tight:} Tag(2,2), SK calculus, Rule 110 achieve exactly 5 bits -
\textbf{Robust:} Zero violations across 6,500+ systems -
\textbf{Optimal:} Computational richness peaks at 5 bits, declining
thereafter

We conjecture this bound reflects a deeper constraint: that universal
computation inherently requires the descriptive complexity to encode
\textbf{Control}---the capacity for conditional, context-dependent state
transitions.

At 4 bits, systems can self-organize but cannot compute universally. The
5th bit---Control---transforms uniform dynamics into conditional
dynamics, enabling branching, gating, and ultimately, Turing
completeness.

We invite proof or refutation of this conjecture in alternative
substrates.

\hypertarget{a.1-cellular-automata}{%
\subsubsection{A.1 Cellular Automata}\label{a.1-cellular-automata}}

For 1D elementary CA with rule number r: - \textbf{Specification
complexity:} K\_spec = popcount(r) (bits set in rule table) -
\textbf{Full complexity:} K\_full = $\log_2(3)$ + popcount(r) $\approx$ 1.58 +
popcount(r)

Rule 110 (binary 01101110): - K\_spec = 5 bits (5 ones in rule table) -
K\_full = 1.58 + 5 = 6.58 bits

\textbf{The UCT theorem uses K\_spec for cross-substrate comparability.}

\hypertarget{a.2-tag-systems}{%
\subsubsection{A.2 Tag Systems}\label{a.2-tag-systems}}

For m-symbol v-tag system:
\[K_U = \log_2(m) + \log_2(v) + \text{production complexity}\]

Tag(2,2): 1 + 1 + 3 = \textbf{5 bits}.

\hypertarget{a.3-turing-machines}{%
\subsubsection{A.3 Turing Machines}\label{a.3-turing-machines}}

For q-state s-symbol TM:
\[K_U = \log_2(q) + \log_2(s) + \log_2(q \cdot s \cdot 2)\]

TM(2,3): 1 + 1.58 + 3.58 $\approx$ \textbf{5.17 bits}.

\hypertarget{c.2-control-state-independence}{%

\textbf{Claim:} Control cannot substitute for State.

\begin{itemize}
\tightlist
\item
  Branching automaton: has Control, but if single-state, behavior is
  deterministic
\item
  Straight-line halter: has State (halts), no Control (no branching)
\end{itemize}

With only Control, cannot track ``have I seen this before.'' With only
State, cannot choose different paths.
